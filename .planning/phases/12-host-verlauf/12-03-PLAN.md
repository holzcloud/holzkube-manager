<objective>
Widen the tracer's path to every value a node records, give the sampler a rate window of its own, and put the host's state where the server hands it out: on `GET /api/v1/host` for the page and the navigation, and on the wall's one answer for the wall and its links.

Purpose: HMON-05's charts need CPU, memory and network, not only sensors -- and without a separate baseline, opening /host would quietly turn the recorded 15-s averages into 3-s samples. HOST-04's wall tile must come from the server's decision (D-06, D-14) and must go grey when the sampler stalls (D-11).
Output: complete `HistoryValues`, a sampler-only baseline, the restart/gap test, `View.Health`, `Collector.Latest`, the wall's `host` field and its end-to-end tests.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| wall link (a URL on a television) → GET /api/v1/clusters/{id}/wall | an unauthenticated screen's credential opens exactly one route; whatever that route carries is public to whoever stands in the corridor |
