<objective>
Der gemeinsame Typ für Geheimnisse (SECRET-01, D-02): `internal/secretval.Secret`. Phase 19 trägt damit die Webhook-Adresse (sie enthält das Token), Phase 20 die Zugangsschlüssel des Exportziels. Er entsteht hier, einmal, und nicht zweimal verschieden.

Der Gedanke dahinter steht in der Recherche von Phase 20 („ein Typ, der nicht ausgeben kann, ist ein Wächter, der nicht vergessen werden kann"): eine Redaktion an jeder Fehlerstelle ist eine Regel, die jemand beim nächsten Log-Aufruf vergisst; ein Typ, der sich nirgends im Klartext ausgeben lässt, ist es nicht. Der Plan hat eine Besonderheit, die ein naiver Typ übersieht: `fmt` kann an einem **nicht exportierten** Feld einer Struktur keine Methode aufrufen und druckt den Inhalt per Reflexion. Ein `Sender` mit einem Feld `url secretval.Secret`, den jemand mit `%+v` ins Log schreibt, würde also die Adresse samt Token drucken, obwohl `Secret` ein `String()` hat. Deshalb liegt der Wert hinter einem Zeiger: dort druckt `fmt` eine Adresse im Speicher und keinen Inhalt.

Was dieser Plan nicht liefert: keinen Aufrufer. Weder der Sender (Plan 04) noch die Einstellung (Plan 05) noch Phase 20 existieren hier. Der Wächter über `Reveal` beginnt deshalb mit einer leeren Liste; wer `Reveal` zum ersten Mal ruft, trägt seine Datei mit Begründung ein, und der Wächter zwingt ihn dazu.

```go
package secretval

// Redacted is what a Secret prints as, in every channel. It is audit.RedactedMarker (marker_test.go holds the two together).
const Redacted = "<redacted>"

var ErrRedacted = errors.New("secretval: the value is the redaction marker and not a secret")
var ErrNotAString = errors.New("secretval: a secret is a string")

// Secret holds one secret value. The zero value is "not set".
type Secret struct {
	_ [0]func() // not comparable with ==: Equal compares in constant time
	v *string   // behind a pointer so that fmt cannot print it by reflection from an unexported field
}

func New(v string) Secret            // New("") is the zero value
func (s Secret) Reveal() string      // the one way out; every caller is on the list in reveal_guard_test.go
func (s Secret) IsSet() bool
func (s Secret) IsZero() bool        // for the omitzero tag
func (s Secret) Equal(o Secret) bool // constant time

func (s Secret) String() string                    // Redacted when set, "" when not
func (s Secret) GoString() string                  // the same
func (s Secret) Format(f fmt.State, verb rune)     // the same, for every verb
func (s Secret) LogValue() slog.Value              // slog.StringValue(String())
func (s Secret) MarshalText() ([]byte, error)      // the same
func (s Secret) MarshalJSON() ([]byte, error)      // the same, as a JSON string
func (s *Secret) UnmarshalText(b []byte) error     // accepts a clear value; ErrRedacted for the marker
func (s *Secret) UnmarshalJSON(b []byte) error     // a JSON string only (ErrNotAString), null is a no-op, ErrRedacted for the marker
```

Die Konvention (steht auch im Paketkommentar):
1. **Im Ruhezustand** ist ein Geheimnis ein einfacher `string` im Datensatz des Stores (Datei 0600 in 0700). Der Datensatz-Typ druckt das Feld selbst nie (er trägt `Format`, `String`, `GoString` und `LogValue`, die `<redacted>` setzen); Phase 19 macht das für `model.AlertingSettings`.
2. **Der Typ betritt und verlässt den Datensatz an genau einer Stelle**: `secretval.New(rec.Feld)` beim Laden, `s.Reveal()` beim Schreiben. Diese Stelle steht auf der Liste in `reveal_guard_test.go`.
3. **Alles darüber trägt `Secret`**: Dienste, Clients, Sender. `Reveal` ruft nur, wer das Geheimnis wirklich auf die Leitung oder in die Datei schreibt.
4. **Ansichten (Antworten der API) tragen nie ein `Secret` und nie einen String davon**, sondern `gesetzt: bool` (und, wo es kein Geheimnis ist, einen Teil wie den Host). Eine Anfrage darf ein `*Secret` zum Empfangen tragen; ein ausgelassenes Feld (`nil`) heißt „behalten“, ein leerer String „entfernen“.
5. **Die Audit-Allowlist** (`internal/audit/redact.go`) nennt das Feld nie; der Standardzweig schreibt dann `<redacted>`.

Was der Typ nicht schützt: einen String, den jemand aus `Reveal()` in eine Variable, einen Fehlertext oder ein Log kopiert. Deshalb ist die Liste der Aufrufer kurz und begründet.
