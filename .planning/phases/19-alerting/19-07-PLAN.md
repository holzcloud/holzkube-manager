Die Karte und die Beschreibung (ALRT-07, ALRT-08): was der Betreiber sieht, wenn er den Kanal einrichtet, und was die Dokumentation über ihn sagt. Die Regel des Betreibers vom 2026-09-26 gilt hier unverändert: **ein Feature ist erst fertig, wenn das README es sagt**, und jeder Befund geht ins Ledger und nicht in die Erinnerung.

Drei Aufgaben. Die erste ist die Oberfläche, und ihre Besonderheit ist ein Fehler, den man an einer Karte für ein Geheimnis leicht macht und der nicht im DOM steht: **react-query hält die `variables` einer Mutation im Mutations-Cache**, bis sie nach `gcTime` (fünf Minuten) eingesammelt wird. Eine Adresse mit Token, die per `useMutation` gesendet wird, läge dort. Die Karte setzt `gcTime: 0`, setzt die Mutation nach dem Erfolg zurück, und ein Test liest den Mutations- und den Query-Cache nach der Marke ab. Der Rest folgt dem Muster der Karte „Wall links“ und der Abschnitte von `Backups.tsx`: Zod-Schema in `api.ts`, `DataTable` für die Ereignisse, die Sätze kommen vom Server.

Die zweite ist die Dokumentation, mit drei Besonderheiten, die aus den Beschlüssen kommen: die Sätze, die behaupteten, das Produkt alarmiere nicht (der Paketkommentar des Exporters ist in Plan 06 berichtigt; der Leitfaden und die Karte der Metriken sind hier dran), die Grenzen, die D-03 ausdrücklich benennt (läuft der Pi nicht, geht nichts hinaus; ein zurückgerolltes Binary verliert die Adresse), und der Dienst, den der Leitfaden **nicht** nennen darf, bis ihn jemand probiert hat. Ein Test hält das, weil Prosa, die niemand wieder liest, von selbst veraltet. Die dritte ist das Ledger und das Gate: was die Phase nicht belegen kann, steht offen darin, und das Gate über alles, was hier läuft, hat eine Liste dessen, was nicht läuft.

Kein Bild im README: die Funktion ist eine Karte in den Einstellungen und kein Bildschirm für sich (`CLAUDE.md` verlangt ein Bild, „wenn die Funktion ein Bildschirm für sich ist“); `web/fixtures/demo.json` und `docs/screenshots/` bleiben unberührt. Entscheidungen, die dieser Plan trägt: D-02 (die Adresse nur schreibend, nie angezeigt), D-03 (die Warnung bei `http://`, das Ziel sichtbar, die Konsequenzen im Leitfaden: Rollback, Gotify nicht genannt, kein Heartbeat), D-04 (der Probelauf sendet nicht, und die Karte sagt es).

```ts
// the JSON of GET and PUT /api/v1/alerting; lists are never null on the wire but the schema tolerates null (api.nulls.test.ts)
interface AlertingView {
  state: 'not-set-up' | 'paused' | 'dry-run' | 'on'
  configured: boolean; enabled: boolean; dry_run: boolean
  target: { display: string; scheme: string; host: string; port: string; plain: boolean; loopback: boolean } | null
  kinds: { kind: string; label: string; enabled: boolean }[]          // all eight
  changed_at?: string
  delivering: { at: string; attempts: number; next_attempt_at?: string; class: string } | null
  last_delivery: { at: string; ok: boolean; class: string; status: number; attempts: number; next_attempt_at?: string } | null
  last_test: { at: string; ok: boolean; class: string; status: number; attempts: number } | null
  open: { kind: string; severity: 'warning' | 'critical'; sentence: string; since?: string; announced: boolean }[]
  events: { id: string; at: string; kind: string; transition: string; severity: string; sentence: string; delivery: 'pending' | 'delivered' | 'failed' | 'not-sent' }[]
}
// PUT body: { url?: string; enabled?: boolean; disabled_kinds?: string[] }   (url omitted keeps, "" removes)
// POST /api/v1/alerting/test answers { at: string; ok: boolean; class: string; status: number }
```

Das Wording der Klassen für das Ergebnis der Testnachricht (die Karte druckt einen Satz zur Klasse und nie einen Text der Gegenstelle): `ok` zugestellt (mit Status), `timeout` die Adresse hat nicht innerhalb von 10 Sekunden geantwortet, `unreachable` die Adresse war nicht zu erreichen, `tls` dem Zertifikat der Adresse wird nicht vertraut, `refused-by-endpoint` der Dienst hat die Nachricht abgelehnt (Adresse prüfen), `rate-limited` der Dienst bittet um Geduld, `server-error` der Dienst meldet einen Fehler, `redirect` die Adresse leitet weiter (die endgültige Adresse eintragen), `bad-address` die Adresse ist nicht benutzbar. Der Wortlaut ist Ermessen, die Zuordnung Klasse zu Satz ist gepinnt.
