<objective>
Das Dokument und der Sender (ALRT-04, ALRT-05): was an die Adresse des Betreibers geht, und wie es dorthin kommt, ohne dass die Adresse irgendwo herauskommt.

Zwei Dinge in einem Plan, weil sie dieselbe Grenze haben: alles hier verlässt den Daemon Richtung Dritter. Das Dokument ist eine **veröffentlichte Schnittstelle** (D-01, costly: Empfänger schreiben Skripte dagegen); es hat deshalb eine Version, stabile Schlüssel, ein Golden-File und einen Test, der das Vokabular festnagelt. Der Sender ist die Stelle, an der die Adresse mit dem Token auf die Leitung geht (D-02); deshalb ist er die eine Stelle in der Phase, die `Reveal` ruft, und deshalb gibt er keine Fehler zurück, sondern Klassen: die Recherche hat gemessen, dass `url.Parse` und `Client.Do` die ganze Adresse in ihren Fehlertext schreiben, und dieser Text wäre ohne Weiteres im Log, im Audit-Ergebnis und in einer Antwort gelandet.

Die Frist-Lehre aus Ledger 137 (certwatch las ein halbes Jahr nichts, weil es auf einem Kontext mit Frist lief) kehrt hier um: `net/http` verlangt keine Frist und hängt ohne eine unbegrenzt an einer Gegenstelle, die annimmt und nicht antwortet; der einzige Sender würde dann nie wieder senden. Jeder Versuch bekommt deshalb sein eigenes Budget, und die Wächter dafür beginnen auf einem Kontext ohne Frist.

Was dieser Plan nicht liefert: das Wiederholen und seinen Takt (Plan 05: der Sender gibt `Retryable()` und `RetryAfter`, der Dienst entscheidet), die Einstellung der Adresse (Plan 05), die Routen (Plan 06). Der Tracer läuft trotzdem durch alle Schichten dieses Plans: ein echter `httptest`-Empfänger, der echte Sender, die echte Prüfung der Adresse.

Entscheidungen, die dieser Plan trägt: D-01 (Webhook, Dokument als Schnittstelle), D-02 (Adresse als Geheimnis: nie in Fehlern, Logs, Antworten), D-03 (`http://` erlaubt mit Warnung, private Ziele nicht gesperrt, Zielhost sichtbar, Hilfsschlüssel `title`, `message`, `text`, Retry mit Grenze).

Output: `target.go`, `sender.go`, `document.go`, Golden-File, Tests; zwei Einträge in der Liste der Aufrufer von `Reveal`.

type Class string
const (
	ClassOK          Class = "ok"
	ClassTimeout     Class = "timeout"
	ClassUnreachable Class = "unreachable"
	ClassTLS         Class = "tls"
	ClassRefused     Class = "refused-by-endpoint" // 4xx except 408, 425, 429
	ClassRateLimited Class = "rate-limited"        // 425, 429
	ClassServer      Class = "server-error"        // 5xx, 408, anything else odd
	ClassRedirect    Class = "redirect"            // 3xx, never followed
	ClassBadAddress  Class = "bad-address"         // the request could not even be built
	ClassCancelled   Class = "cancelled"           // the daemon is stopping; never recorded
	ClassDryRun      Class = "dry-run"             // set by the service in --dry-run, never by the sender
)

const (
	AttemptTimeout = 10 * time.Second // one attempt: connect, TLS, send, answer
	ResponseLimit  = 4 << 10          // bytes of an answer that are read and thrown away
	MaxRetryAfter  = 5 * time.Minute
	MaxURLLength   = 2048
)

type Result struct{ Class Class; Status int; RetryAfter time.Duration }
func (r Result) OK() bool
func (r Result) Retryable() bool  // timeout, unreachable, rate-limited, server-error

type Sender struct {
	Client  *http.Client  // tests only; NewSender sets one that follows no redirect and has no Timeout
