<objective>
Der Auswerter (ALRT-01, ALRT-02): eine **reine** Funktion `alerting.Assess`, die aus dem vorhandenen Lesemodell eine Liste von Bedingungen macht. Jede Bedingung hat einen stabilen Schlüssel, ein dreiwertiges Urteil (feuert, in Ordnung, unbekannt), eine Stufe und einen Satz. Der Plan baut weder die Übergänge (Plan 03) noch das Senden (Plan 04) noch den Takt (Plan 05); er beantwortet die Frage „was braucht in diesem Augenblick Aufmerksamkeit, und was können wir gerade nicht sagen“.

Die Linie, die den Plan prägt, steht in der Recherche (Befund 1 und Pitfall 1): **nicht gelesen ist nie in Ordnung**. Nach jedem stündlichen Update-Neustart sind `NodeCertificates` und `ConfigDrift` leer und die Knoten in `connecting`; ein Auswerter, der „nicht da“ als „kein Problem“ liest, würde bei jedem Neustart „wieder in Ordnung“ für alles melden. Deshalb ist `Unknown` der Nullwert, und deshalb kennt `Assessment` neben den Bedingungen die Menge `Looked`: ein Eintrag verschwindet nur dann still, wenn dieser Durchgang seinen Bereich wirklich angesehen hat und der Schlüssel fehlte.

Drei Lücken des Lesemodells, die die Recherche gefunden hat, schließt dieser Plan, ohne einen zweiten Leser zu bauen: (1) Knoten-Temperatur und -Platte stehen in keinem Lesemodell, nur in der Live-Lesung, die der Sampler alle 15 s ruft; `HardwareCache` ist der Abgriff dort. (2) Die Plattenlinie eines Knotens (80 und 90 Prozent) existiert nur im Browser; sie wird hier serverseitig festgeschrieben, und ein Test hält sie an den Quelltexten der Bildschirme fest. (3) `host.Health` trägt Sätze und keine Schlüssel; es bekommt ein nicht serialisiertes Feld `Rated` mit jedem bewerteten Wert.

Entscheidungen, die dieser Plan trägt: D-01 (das Vokabular der Arten ist Teil der veröffentlichten Schnittstelle), D-03 (Zustände, Schwellen, Haltezeiten und Hysteresen wie vom Betreiber bestätigt; Zertifikate ab `banner`, Drift erst nach 24 h, Knoten 5 min mit Unterdrückung bei laufendem Auftrag). Die Zahlen, die D-03 nicht nennt (Klärzeiten), sind Ermessen und stehen in `rules.go` als solche; die Recherche führt die Reboot-Dauer als ungeprüfte Annahme (A6), und Plan 07 trägt sie ins Ledger ein.

Output: das Paket `internal/alerting` mit Vokabular, Regeln, `Assess`, `HardwareCache` und Tests; `host.Health.Rated`.

```go
package alerting

type Kind string
const (
	KindNodeUnreachable    Kind = "node-unreachable"
	KindNodeTemperature    Kind = "node-temperature"
	KindNodeDisk           Kind = "node-disk"
	KindHost               Kind = "host"
	KindBackupOverdue      Kind = "backup-overdue"
	KindClientCertificate  Kind = "client-certificate"
	KindClusterCertificate Kind = "cluster-certificate"
	KindConfigDrift        Kind = "config-drift"
)
func Kinds() []Kind                // genau diese acht, in dieser Reihenfolge
func KindLabel(k Kind) string      // die englische Beschriftung der Karte

type Severity string               // "warning" | "critical"; der Nullwert "" ist "keine"
const ( SeverityWarning Severity = "warning"; SeverityCritical Severity = "critical" )
func (s Severity) Rank() int       // "" 0, warning 1, critical 2

type Transition string             // "attention" | "worsened" | "recovered"; TransitionBaseline = "baseline" nur im Ring der Karte

type Verdict int
const ( Unknown Verdict = iota; OK; Firing )   // der Nullwert ist Unknown

type Ref struct {                  // Cluster oder Knoten; Name ist der Name des Datensatzes; JSON im Zustand und im Webhook-Dokument
	ID   string `json:"id"`
	Name string `json:"name"`
}
type Scope struct {                // Subject: Machine-ID, Cluster-ID oder "host"; JSON im Zustand
	Kind    Kind   `json:"kind"`
	Subject string `json:"subject"`
}

type Hold struct{ ForWarning, ForCritical, Clear time.Duration }

type Condition struct {
	Key      string    // stabil; Aufbau je Art unten
	Kind     Kind
	Scope    Scope
	Verdict  Verdict
	Severity Severity  // bei Firing; sonst ""
	Cluster  Ref
	Node     Ref       // leer bei Cluster- und Host-Bedingungen
	Since    time.Time // wenn die Quelle einen Beginn kennt (Drift), sonst zero
	Hold     Hold
	Sentence string    // Firing: der Satz des Problems; OK: der Satz der Entwarnung; Unknown: ""
}

type Assessment struct {
	Conditions []Condition
	Looked     map[Scope]bool   // Bereiche, die dieser Durchgang wirklich angesehen hat: ein fehlender Schlüssel darin heißt "weg"
	Subjects   map[string]bool  // Machine-IDs, Cluster-IDs und "host", die es in dieser Installation gibt
}
```

Scope: `{KindNodeUnreachable, machine}`, `{KindNodeTemperature, machine}`, `{KindNodeDisk, machine}`, `{KindHost, "host"}`, `{KindBackupOverdue, cluster}`, `{KindClientCertificate, cluster}`, `{KindClusterCertificate, cluster}`, `{KindConfigDrift, cluster}`.
