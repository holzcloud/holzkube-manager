<objective>
Success criterion 2 of Phase 13 and the second half of HACT-07: the daemon never carries out a host action itself -- no systemctl, no reboot, no subprocess; it writes one file -- and a guard holds that, seen red against a smuggled process start. And no order is ever left lying where a helper started later would run it by surprise: the daemon withdraws an order that was not picked up in 10 s, and any order it finds at start.

Purpose: `SystemCallFilter=@system-service` does not block exec (it includes @process), so the source guard is the only thing that keeps criterion 2 true (RESEARCH R1). The withdrawal is the net under "installed but not running" (D-13): without it, an order placed while the path unit is stopped would reboot the host whenever somebody starts it.
Output: `fsstore.Claim`, PlaceNew's tests, the Box's pickup timer and startup sweep, `internal/processguard_test.go`.
</objective>

| previous daemon process → next one | an order may outlive the process that placed it |
