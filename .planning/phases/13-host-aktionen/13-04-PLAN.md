<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| data directory (daemon-owned) → root script | root reads a name the unprivileged user controls and can swap between two syscalls |
| root script → journal | whatever the script logs is read by the operator and kept |
| root state directory → daemon | the daemon turns root's file into a statement on the page |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |

| T-13-19 | Elevation of Privilege | order parsing as root | high | mitigate | anchored ERE under LC_ALL=C on exactly one line of at most 64 bytes, fixed argv per action in a case, no eval, no unquoted expansion; 18 malformed shapes rejected; F9 seen red |
| T-13-20 | Information Disclosure | symlink swap into the journal | high | mitigate | the only read is `dd iflag=nofollow`; content never logged, only reason and byte count; symlink to a valid order rejected; F10 seen red |
