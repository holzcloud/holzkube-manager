<objective>
13-12 made Check for updates work. This plan makes the page and the routes honest about a helper that is too old for it, and finishes HACT-04 in the documentation and the pictures.

The daemon cannot ask systemd which helper is installed (D-12: no D-Bus, no AF_UNIX), but it can read the installed script, as it already reads the helper's files to tell whether it is installed. 13-12 gave the script one marker line naming the orders it knows; a script without that line is the helper of 13-01, which knows exactly four. So: the daemon reads that line (bounded, only once Detect has found the script root-owned and writable by nobody else), and the check additionally needs its unit file. When either is missing, the check alone is off, the other four stay usable, the routes refuse the check with 409 before anything is placed, and the page names what to reinstall with the same install commands. The helper's refusal of every word it does not know stays the real lock (13-12 proved it on the frozen older helper); this is the part that keeps the page from offering what would be refused.

Purpose: the operator is never sent into a dialog for an order the installed helper would reject, and is told how to get the check.
Output: `actions.outdated` and the 409, the check button's own reason and notice, the fixtures, README, guide, HOST-HELPER.md, contract and host.png describing five actions, the D-08 desk comparison after 13-12, and the full gate on the Pi. HACT-04 is complete with this plan.
</objective>
