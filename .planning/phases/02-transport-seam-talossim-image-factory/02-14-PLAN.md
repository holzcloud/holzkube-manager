<objective>
Close G-02-16: `Schematic.Canonical()` emits documents the real Factory reads differently, and the
divergence class is unbounded above U+007F.

Purpose: FACT-06 is the whole reason this serialiser exists. A locally computed id is only worth
having if it equals the Factory's, and `representable` refuses only `r < 0x20 || r == 0x7F` while
YAML's line-break set also contains U+0085 and U+2028/U+2029 and its printable set excludes the C1
range and U+FEFF. Nine codepoints were sampled during the audit and four broke it in three distinct
ways: U+2028 makes the emitted document invalid YAML (the Factory answers with a scan error, which
holzkube reports as `502 upstream.factory-unavailable` — verbatim the sentence UAT test 5(b) exists
to exclude), U+FEFF/U+0085/U+009F are refused by the Factory, and a trailing U+0085 is silently
eaten so the stored `kernel_args` and `canonical` disagree about what the image will be built with —
that variant collapsed onto an existing canonical and returned a false `409`.

The audit's own instruction is the shape of this plan: a differential check against the canonical
the live Factory returns, not another transcribed table. Nothing in the repository tests any
codepoint above U+007F, so the measurement comes first and the code change is derived from it.

Output: an opt-in differential guard that reaches above U+007F, a refusal set derived from what it
measured, offline tests that pin every measured class, and a contract that states both the set and
what was never measured.
</objective>
