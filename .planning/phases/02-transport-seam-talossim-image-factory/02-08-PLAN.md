<objective>
Turn `talossim` from a one-RPC tracer target into a credible oracle: the `MachineService`
subset the product actually reaches, real in-memory COSI state served to the unmodified
client, the three server streams, and a running guard that fails when the sim drifts behind
the production client.

Purpose: this is the second half of TRANS-06 🚫, the phase's only release blocker. Plan 02-01
proved the transport (real listener, real mTLS, one RPC through the seam); a transport that
answers one method is not a thing other phases can test against. ROADMAP ordering constraint
\#1 makes this a correctness dependency for every phase ≥ 3, and plan 02-03's nine scenarios
have nothing to script until the methods and the streams exist.

Output: `internal/talossim/machine.go` completed, `cosi.go`, `stream.go` and the
method-coverage guard.
</objective>

<why_this_plan_exists>
This plan is the W-2 split of plan 02-01, recorded in that plan's `<scope_decision>`. 02-01
carried 18 files and the phase's largest estimate while owning the release blocker, and its
seam proof — the whole of TRANS-02 — ran last, behind the heaviest task in the phase. Lifting
that heaviest task here moves the seam proof to roughly 50% of 02-01's context window and gives
this work a fresh window of its own.

The split is not free and the cost is declared, not hidden: the phase went from four waves to
five, and plan 02-03 now declares `depends_on: ["02-01", "02-08"]`. There is one compensating
gain — the method-coverage guard below walks `internal/talos` for machinery-client call sites,
and by wave 2 that package contains `dial_direct.go`'s `Probe` as well as `client.go`, so the
guard sees more real call sites than it could have seen inside 02-01.
</why_this_plan_exists>

`cosi.go`: build the in-memory COSI state with the wiring confirmed in CONTEXT
`<research_flag_resolved>` — `state.WrapCore(namespaced.NewState(inmem.Build))`, wrapped by
`protobuf/server.NewState`, registered with `cosiapi.RegisterStateServer` on the **same** gRPC
server as `MachineService`. Registering it on a second server would still let a hand-written
test pass while the production client's `Client.COSI` adapter, which dials one connection,
finds nothing — and that is the class of divergence TRANS-06 exists to prevent. Resolve the
exact import paths against the resolved module source rather than from memory; if they differ
from the paths named here, follow the module.

Expose `func (s *Server) COSI() state.State` so a test can seed resources, and seed one
`SystemInformation`-shaped and one `NodeAddress`-shaped resource at construction, so a COSI
read has something truthful to return before any test does anything. Plan 02-03's `k8s_down`
scenario removes k8s-related resources from this state, so seeding must go through the same
accessor a scenario would use.

`stream.go`: implement `Logs(*machine.LogsRequest, grpc.ServerStreamingServer[common.Data])`,
`Dmesg(*machine.DmesgRequest, grpc.ServerStreamingServer[common.Data])` and
`Events(*machine.EventsRequest, grpc.ServerStreamingServer[machine.Event])`. These are type
aliases onto gRPC generics, not defined interfaces — implement the generic directly.

Each stream emits a bounded, configurable sequence and honours the stream context's
cancellation. Bounded is a requirement, not a nicety: an unbounded emitter that a stalled
consumer cannot drain fills memory and turns every one of plan 02-03's scenario tests into a
flake. Emission is driven from a per-server channel so that plan 02-03 can stall it for
`slow_log_consumer` without touching this file's shape — that indirection is the reason the
channel exists, so do not collapse it into a direct loop.
  </action>
