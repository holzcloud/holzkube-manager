<objective>
Close G-02-10: the repository name in an asset reference can split across a line break, and the test
named for that property does not measure it.

Purpose: `ReferenceValue` inserts `<wbr />` at path separators and sets `break-normal`, and the
comment argues that this prevents `metal-installer` from wrapping into something a reader takes for
`installer`. It does not. UAX #14 gives a break opportunity after U+002D HYPHEN-MINUS — line-break
class HY — independently of `overflow-wrap` and `word-break`, and `break-normal` does not remove it.
At the default viewport `metal-installer-secureboot` breaks after a hyphen and the first line reads
`metal-installer`: the ordinary installer name standing as the visible head of a SecureBoot
reference. That is the ISO/installer drift `installer.go` says the whole resolution exists to
prevent, arriving in the one place an operator reads it.

The test at `images.test.tsx:849` is named `cannot split a repository name across a line break` and
asserts that the class string lacks two utilities and that the text content is intact. It passes
while the name is split. Only `metal-installer` was ever considered; the four-name set was already
enumerated in this phase's own live matrix and the other three were never looked at. And the manual
method was unsound independently of its result: break windows are not monotonic in width — the audit
measured splits at 40-115px and again at 174-238px with a safe gap between them, and the 400px
viewport that was tested produced a column inside that gap. "Narrow until cramped" passes through a
safe window and can never establish this property.

So the property has to be measured, and jsdom lays nothing out. This plan says plainly where the
test has to run: in a real layout engine. It adds one, runs it in CI, and uses it for the two
measurements this phase owes — the line boxes of all four names across a width sweep, and the dialog
width plan 02-15 fixed but could not measure.

Output: a browser test project, a measured guarantee for four names at every width in a swept range,
and a fix that changes layout without changing a single character of the reference.
</objective>
