<objective>
Turn a schematic ID into the exact, correct artifacts an operator can actually use: ISO,
PXE and installer URLs with a version-resolved repository name and no hardcoded
architecture; an honest version list; the kernel-args warning; and a persisted record behind
the store's entity seam.

Purpose: ROADMAP success criterion 4 in full. `PITFALLS.md` §P9 documents four distinct
silent-divergence bugs in this area, three of which are addressed here — the version-dependent
installer repository name, the prerelease-at-the-end-of-the-list trap, and the
`installer`/`initramfs` asymmetry that makes an ISO and its installed system differ. Each is
a bug that reports success.

Output: URL derivation, version filtering, the warning, `model.Schematic` behind
`store.Schematics()`, schema version 2, and the schematics contract section that plan 02-06
codes against.
</objective>
